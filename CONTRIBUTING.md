# Contributions

The Reduktive OPC UA SDK is not a community-development project. Reduktive
Limited does not accept source code, patches, pull requests, or other proposed
code contributions through this repository. Please do not create or publish a
modified version in order to propose a change.

Factual bug reports and evaluation feedback that contain no SDK source code,
patch, or confidential information may be submitted through
[GitHub Issues](https://github.com/reduktive/opc-ua-sdk/issues). Submission does
not create a support obligation or a duty to review, keep confidential, accept,
or use the material.

Do not use a public issue for a suspected vulnerability. Follow
[SECURITY.md](SECURITY.md) and report it privately to security@reduktive.com.

The permissions and restrictions governing the SDK are stated in
[LICENSE](LICENSE). Nothing in this file grants permission to modify or
redistribute the SDK.
