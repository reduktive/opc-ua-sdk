# Security Policy

The Reduktive OPC UA SDK is intended for security-sensitive industrial and IIoT
software. Although the public SDK is currently an incomplete pre-release,
Reduktive Limited welcomes responsible reports of suspected vulnerabilities.

## Reporting a vulnerability

Do not open a public issue or discussion for a suspected vulnerability. Report
it privately to security@reduktive.com.

Please include the affected public version, impact, relevant configuration,
reproduction steps, and a proof of concept where practical. Do not include live
credentials, personal data, customer data, or other third-party confidential
information. If encrypted reporting is necessary, first request current secure
submission instructions from the same address.

Reduktive will assess reports and coordinate any disclosure individually. This
policy does not promise a response time, fix, support period, bounty, or public
credit.

## Supported versions

The `v1.0.0-rc.N` release candidates are pre-release evaluation releases,
not supported production releases. Only the latest published prerelease is
relevant for investigation; earlier prereleases may not receive fixes.

Commercial production use requires a separate written commercial licence, and
Reduktive does not issue those licences for prerelease versions. Terms for
supported commercial versions, security maintenance, and end-of-support are
defined by the applicable commercial agreement.

## Advisories

When public disclosure is appropriate, Reduktive will publish an advisory and
identify the affected and corrected public versions in the public repository or
release notes.
